# Porsche Sales Intelligence

## 📌 Visão Geral

O **Porsche Sales Intelligence** é um dashboard de análise de vendas que permite acompanhar o desempenho comercial de veículos Porsche por modelo, ano-modelo, cidade, método de pagamento e período.

## Funcionalidades

### Filtros

Permite filtrar os dados por:

- Modelo Porsche
- Ano-modelo
- Cidade
- Método de pagamento
- Intervalo de datas

Todos os indicadores e gráficos são atualizados automaticamente conforme os filtros selecionados.

### Indicadores (KPIs)

O dashboard apresenta:

- Quantidade de registros
- Valor total das vendas
- Ticket médio
- Ano-modelo com maior volume de registros

### Visualizações

- **Modelos mais vendidos:** ranking dos modelos com maior número de vendas.
- **Distribuição por ano-modelo:** comparação do volume de vendas por Model Year.
- **Modelos líderes por cidade:** identifica o modelo mais vendido em cada cidade.
- **Métodos de pagamento:** distribuição das vendas por forma de pagamento.

### Insights Automáticos

O sistema destaca automaticamente:

- Modelo mais vendido
- Cidade com maior concentração de vendas
- Ano-modelo mais frequente

## Observações

- Registros com datas inválidas são desconsiderados quando filtros de período são aplicados.
- Os valores apresentados representam a soma das vendas registradas na base, incluindo registros cancelados.
- Os valores monetários são exibidos em USD.

## Tecnologias

- HTML
- CSS
- JavaScript (Vanilla JS)

Sem dependência de bibliotecas externas.
